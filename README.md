# 🏫 AI School Surveillance System

## 📌 Project Description
This project is a simple AI-based school surveillance prototype designed
to demonstrate real-time person detection using computer vision.

## ✨ Features
- Live camera monitoring
- Face/person presence detection
- Real-time security status
- Security event logging
- Simple and user-friendly interface

## 🛠️ Technologies Used
- Python
- OpenCV
- Computer Vision

## ▶️ How to Run

1. Clone or download this repository.
2. Install the required library:

pip install -r requirements.txt

3. Run the program:

python school_surveillance.py

4. Press **Q** to stop the surveillance system.

## 🔒 Privacy Note
This educational prototype focuses on detecting presence rather than
identifying individuals. Any real-world surveillance system should follow
privacy laws, obtain appropriate consent, and protect collected data.
